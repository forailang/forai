# forai Language Reference

forai is a statically-typed, compiled language with readable syntax and strong type
inference. All blocks are `end`-delimited. Comments start with `#`.
`print()` is a builtin — no import needed.

Run `fai doc lang` to list all language topics, or `fai doc lang.<topic>` to drill in.
Examples: `fai doc lang.variables`, `fai doc lang.modules`, `fai doc lang.functions`.
